# 模组设计评审（可玩性 × 平衡 × 落地）

> 日期：2026-07-28  
> 范围：原 `todo.md` 12 个独立方向 + PersonalKit 小功能  
> 原则：**可玩性第一**；有代价、可设置、轻松模式；事件驱动/有界脉冲；soft-link 不硬依赖；与垦壤/田作「维护循环」同气质，**不做心情税农场**。  
> 状态：已停止「12 个一起批量实现」。空壳脚手架与半成品 Ledger/WorkshopWear **不算定稿**，以本文为准。

---

## 0. 评审标准（写代码前先过这五关）

| # | 标准 | 不及格的样子 |
|---|------|--------------|
| 1 | **玩家有没有主动决策？** | 只有被动 debuff / 每周弹窗 |
| 2 | **决策是否改变局面？** | ±2 心情、±3% 数字，感觉不到 |
| 3 | **失败是否「公平可读」？** | 门被悄悄打开、银被暗扣、原因在日志第三页 |
| 4 | **会不会和原版双重征税？** | 饿了 + 粮库心情；困了 + 梦债精神打击 |
| 5 | **关掉/轻松模式后还像 RimWorld 吗？** | 关不掉的扫图、关不掉的全图 debuff |

**额外口味（本系列）**

- 维护循环可以，但必须有 **Overwork / 赊账 / 黑市 / 赶工** 这类「明知有代价仍想按」的按钮。  
- 叙事可以，但标签/口碑必须来自 **事迹**，不是 RNG 贴条。  
- 地图条件休眠（无河、无疫、无械）是优点，不是缺点。

## 2. 逐项深挖

### 2.1 黑市邮筒 Dead Drop — **S（最值得做）**

**原案一句**：地图边缘藏匿点，灰色订单，被发现有风险。

**为什么有意思**  
- 玩家**主动**接单/交货/放货，不是被系统扣分。  
- 回报与风险同屏：银/违禁/血清 vs 派系敌对、帝国注视、伏击。  
- 和 Trait Extractor「玩家上架血清」、PersonalKit 谈价形成犯罪经济闭环。  
- 无订单时几乎零成本（边缘点休眠）→ 性能与心智负担都友好。

**平衡要点**  
| 项 | 建议 |
|----|------|
| 刷新 | 每 3～7 天 1 单，地图最多 1 个活跃 Drop |
| 利润 | 毛利约为正常贸易 1.3～2.0×，但货物常残次/违禁 |
| 发现 | 交货/取货时 roll；警觉派系、 thrumbos 不相关；殖民者「正直」特性降低参与欲或提高暴露 |
| 失败 | 暴露 → 一次关系打击 + 可能的「搜查队」小事件，**不**直接灭村 |
| 血清 | soft-link：有 TE 才出现血清订单；无 TE 用器官/毒品/情报替代 |
| 轻松 | 发现率减半；无搜查队 |

**核心循环（可玩）**  
1. 研究或中期事件解锁「边缘邮筒」标记/建筑（隐蔽小屋或石堆）。  
2. 信件/Gizmo 出灰单：要货 / 给货 / 双向。  
3. 殖民者跑边送/取（Job），途中可被目击。  
4. 成功：货+银；信用（黑市声望）↑ → 更好订单。  
5. 失败：声望↓、某派系 −15～−30、偶发搜查。

**不要做**  
- 全自动「挂机收黑钱」。  
- 无限堆叠订单变成第二贸易商。  
- 与原版走私无区分的纯加价商店。

**体量估计**：建筑 1 + Job/WorkGiver + Game/MapComponent 订单状态 + 2～3 事件 + 设置。约等于一个「中等 Fieldcraft 阶段」。

### 2.2 匠人署名 Artisan Mark — **S（小而美）**

**为什么有意思**  
- 几乎零操作：做出来就刻名字 → 检视有故事。  
- 制作者阵亡 → 遗物心情，是 RimWorld 最对味的情绪。  
- 平衡极好控：默认**只心情/叙事**，战斗加成可选且极小。

**平衡要点**  
| 项 | 建议 |
|----|------|
| 记录对象 | 武器、服装、雕塑、人造躯体；一次性消耗品不记 |
| 战斗加成 | 默认 **关**；若开：同房间制作者存活时命中/伤害 **+2%** 封顶，不叠多层 |
| 穿着心情 | 穿「自己做的」+1～2；穿「已故挚友做的」+3～4（限 1 件） |
| 恨屋及乌 | 仅当制作者曾大规模屠杀/囚犯器官且被派系记忆 —— **二期**，一期不做敌人 AI 仇恨 |

**核心循环**  
做东西 → 名字留下 → 人还在时轻微自豪 → 人没了变成遗物。无日常微操。

**不要做**  
- 全图扫描「谁的剑最近」。用 ThingComp 存 maker pawn id / name 即可。  
- 把所有工艺品变成强制传奇。

### 2.3 工坊损耗 Workshop Wear — **A（重设计）**

**原案问题**  
- 「每单磨一点 → 修」容易变成**第二个管道堵塞式家务**，没有决策只有义务。  
- 全自动注入所有 Bench（含研究台）会让玩家觉得「模组在阴我」。  
- 速度降到 45% 对中期产能过狠，且与原版清洁/电力故障叠乘很恶心。

**重设计：以「赶工」为英雄按钮**  
1. **默认磨损很慢**，正常玩一周才需要一次保养（轻松模式更慢）。  
2. **赶工 Gizmo**（建筑上）：24h 内制作速度 +20%～+30%，磨损 ×2，结束时有小概率「卡壳」（暂停账单直到修理）。  
3. **两档修理**  
   - 马虎：钢材少、快、只回 40%～60% 状态，有失败变糟可能  
   - 精修：零件 + 高手工、慢、满状态并清「卡壳」  
4. **作用域白名单**：灶、锻、机工、裁缝、药实验室、制造台；**默认不含**研究台/雕塑桌（设置可加）。  
5. 检视用四态文案：良好 / 旧 / 磨损 / 故障 — 少用 0～100 数字轰炸。

**和田作/垦壤对齐的点**  
「用就要养」，但田作有休耕/绿肥等**策略选项**；工坊必须有赶工/马虎/精修，不能只剩「去修」。

**平衡**  
| 项 | 建议 |
|----|------|
| 基础磨损 | 约 80～120 次标准账单 → 到「磨损」 |
| 故障 | 仅「故障」态停止或极慢；不爆炸（除非 dev/极端设置） |
| 赶工 | 明确按钮，AI 不自动赶工 |
| 轻松 | 磨损 ×0.5，无故障，只有速度下降 |

**半成品代码**：已有 Comp 注入 + 修理 Job，**方向可用，数值与白名单需按本文改**，研究台应移出默认列表。

### 2.4 流言口碑 Rumor Mill — **A（事迹驱动）**

**原案问题**  
- 若标签 RNG 出现 → 心理学模组式心情税，玩家无法「回应」。  
- 与 Ideology 戒律、社交 Fight 可能叠床架屋。

**重设计**  
- **标签只从事件写入**（前 6 个就够）：  
  1. 可靠（多次成功救援/护理）  
  2. 手黑（器官收割、处决、恶意伤害）  
  3. 怕血（见血精神冲击次数）  
  4. 抠门（拒绝贸易礼物？或低社交送礼 — 慎用）  
  5. 被抽过神经（TE soft-link）  
  6. 战英雄 / 逃兵（袭击中击杀或逃跑）  
- **衰减**：30～60 天无强化则降级/消失。  
- **玩家能动**：葬礼、表彰（小仪式 Job 或聚会）、监禁「封口」等 — 一期至少要有「社交闲聊扩散/压制」之一。  
- **效果幅度**：招募意愿 ±8%、商队价格 ±3%～5%、内部社交意见 ±10 — **可感但非定局**。  
- 同一 pawn **最多 2 个活跃标签**，防止脸谱印章墙。

**不要做**  
- 每小时全员互相传播扫描。  
- 标签直接导致精神崩溃（与原版特质抢活）。

### 2.5 聚落账房 Ledger — **A（大改，原案不直做）**

**原案问题（已踩坑）**  
- 每周「口粮/药/电抽象成本」信 **没有决策**，是报表。  
- 储备不足再扣心情 ≈ 原版饥饿/用药压力的**双重税**。  
- 「信用」若只靠环境扣分，玩家会关模组，而不是去还债。  
- 半成品里 `PriceFactor` 全局加价 + 营养全 Def 扫描，味道像惩罚插件。

**重设计：赊账是按钮，不是天气**  
1. **信用分 0～100**：主要随「是否按期还赊账 / 是否毁约 / 大额诚实交易」变。  
2. **交易界面选项「赊购」**（一期可先做：成交时若银不足，差额入债，而不是静默加价）。  
3. **债**：有到期日；到期可还清 / 展期（信用微损）/ 违约（信用大损 + 讨债事件）。  
4. **每周账本**改为**可选**或仅在「有债 / 信用<40 / 玩家点查询」时出现 — 减少噪音。  
5. **储备目标**：默认**只做 UI 提示与历史曲线**，不挂 Thought；设置里才允许「低储备焦虑」心情。  
6. **电力银**：**删除抽象扣费**。电力压力交给原版与工坊；账房不扮演第二经济模拟器。  
7. 与 PersonalKit：谈价更狠 → 更易赢银也更易**敢赊** → 信用博弈，而不是抵消 buff。

**平衡**  
| 项 | 建议 |
|----|------|
| 赊购上限 | creditScore × 10～20 银，随派系 |
| 利息 | 无或极低；主要惩罚是违约事件 |
| 讨债 | 要银或要货；可拒 → 关系与信用；轻松模式只信件不派兵 |
| 价格 | **不要**全局永久加价；改为低信用时「拒绝赊购 / 部分商品不卖」 |

**结论**：理念对（经济要有张力），但必须从「环境税」改成「金融杠杆」。半成品应重写核心，不宜打补丁凑合。

### 2.6 学徒契约 Apprentice Bond — **B**

**有意思的点**：中前期双人成长、导师阵亡创伤 — 人味足。

**平衡雷区**  
- XP 分享极易变成 **双倍升级外挂**。  
- 强制师徒 UI 后期无用却占操作。

**设计约束**  
| 项 | 建议 |
|----|------|
| 绑定 | 玩家手动指定 1 导师 + 1 学徒，同技能树一条 |
| XP | 学徒仅在**同房间、同学科技工作**时获得导师本次获得 XP 的 15%～25%；导师得 5%「教学」 |
| 日帽 | 学徒每日从契约获得的 XP 有硬帽 |
| 心情 | 绑定 +2/+2；拆约临时 −3；导师死 −8～−12 衰减 |
| 出师 | 学徒技能 ≥ 导师 −2 或满 X 天 → 仪式（可选）→ 解绑小 buff |
| 后期 | 设置「殖民地人数 > N 自动暗示解绑」或一键解散全部 |

**不要做**：全局被动光环、跨地图传 XP、多对多师徒网。

### 2.7 疫线检疫 Quarantine Line — **B（休眠式）**

**有意思的点**：空间决策（谁进隔离区、门控、探视）比再叠 hediff 更像游戏。

**平衡 / 体验**  
- **健康时完全休眠**（无 Job、无 tick 逻辑）— 否则 400 天无病也占心智。  
- 有病才：检疫区 designation、隔离门协议、探视风险。  
- 严格执行：传播↓，隔离者心情↓、医护工作↑ — 经典权衡。  
- 商队带病 / 动物疫源：有趣但要控制频率。  
- 与原版免疫/医疗科技兼容；不取代药。

**风险**：医院微操党喜欢、沙盒轻松党会恨 — **设置一键关传播修正**。

### 2.8 残骸图谱 Salvage Atlas — **B**

**有意思的点**：械战有长期沉洞，不是研究条替代品。

**平衡**  
- 碎片 ≠ 研究点；解锁「一次性蓝图 / 小强化 / 拆解配方」。  
- 失败拆解：丢碎片 + 小爆炸/火焰风险（可读、可救）。  
- 进度有界（每个分支 3～5 级），防无限数值。  
- 无械图完局几乎不出现 — 可接受。

**不要做**：直接 +20% 全伤害的永久全局 buff 树。

---

### 2.9 边防更鼓 Watch Roster — **C（降级）**

**原案问题**  
- 完整排班 ≈ 再做一个时间表 UI，和原版 Schedule / 多个 Guard mod 撞车。  
- 「无人值更 → 门未锁」**不公平**：玩家看不见的模拟背叛感极强。

**降级方案（若做）**  
- **岗哨建筑/标记 1～3 个**；夜间有人站岗 → 袭击预警 +0.5～1.5h 或火灾发现更快。  
- 空岗 → **只有**「预警更短 / 夜间移动略慢发现火灾」，**绝不**自动开门、绝不提高袭击强度。  
- 不做全员更鼓表。

**优先级低于** Dead Drop / Wear / Rumor。

---

### 2.10 河权渡口 Ford Rights — **C**

**有意思**：有河地图多一层经济；无河休眠 — 性能友好。

**平衡**  
- 过路费：每商队 **小额**（50～150）且日/季帽，防印钞。  
- 渔获：慢、少，点缀。  
- 洪水：少见，冲毁渡口要修 — 可读。  
- 垦壤改河道 soft-link：二期；一期可只做渡口。

**定位**：彩蛋/情景 mod，不当系列门面。

---

### 2.11 梦债 Dream Debt — **D（砍或改）**

**原案问题**  
- 与原版休息、精神、刺激剂、生物组昼夜仪**严重叠床**。  
- 若被动攒债：要么永远有人在债里（噪音），要么被优化成必开挂。  
- 「灵感/速度」若值得，则 meta 永远透支；若不值得，则系统死亡。

**唯一可接受形态**  
- **自愿通宵 Gizmo**（类似工坊赶工）：今晚不睡，明后日强制补睡窗口 + 临时速度/灵感 chance。  
- **禁止**环境自动梦债 + 精神打击双管。  

**建议**：不独立成包；若要，塞进 PersonalKit「战术通宵」一个按钮。

---

### 2.12 冷链仓储 Logistics Cold — **D（不独立）**

**原案问题**  
- 原版腐烂 + 冷库已经讲完主故事。  
- 再做库龄/FIFO 易变微操；与田作压力同季叠加强。  
- 唯一独特钩子是 **TE 血清温敏**。

**建议**  
- Trait Extractor：血清 `Comp` 高温变质/排异↑。  
- PersonalKit：库存提示 QoL（可选）。  
- **不要**再做一个 Logistics Cold 大包。

## 4. 和现有包的咬合图

```
垦壤 Landworks ──维护──┐
田作 Fieldcraft ──养地──┼─ 气质：用就要养、有赶工/休耕式按钮
工坊 Wear（重设计）────┘

特性提取 TE ──血清──┬─ 黑市 Dead Drop（上架/灰单）
                   └─ 冷链逻辑（并入 TE，不独立）

PersonalKit 谈价 ──张力── 账房（赊账杠杆，非全局加价）
                └── QoL 小功能

匠人署名 ── 全包通用叙事层（低耦合）
流言口碑 ── TE 污名 soft-link；事迹来自战斗/医疗/犯罪
```

**不要同时开的「压力叠乘」组合（默认设置下）**  
- Ledger 低储备心情 + 原版饥饿（账房默认关心情）

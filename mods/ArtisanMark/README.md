# 匠人署名 Artisan Mark

RimWorld 1.6。做出来的武器、服装、雕塑会**刻上制作者的名字**——几乎零微操的叙事模组。

## 理念

> 人在，是自豪；人不在，是遗物。

不是数值膨胀包。默认只有检视署名与轻微心情；战斗加成**默认关闭**。

## 启用

1. **Harmony**
2. 模组列表启用 **匠人署名 Artisan Mark**

路径：`Mods/ArtisanMark`

## 玩法

1. 殖民者在工作台做出**武器 / 服装 / 雕塑艺术品 / 假体**时，物品自动署名。
2. 检视面板显示 **Made by X** / **制作者：X**。
3. 穿着**自己做的**衣服：小幅正面心情（默认 +2，可调）。
4. 穿着**已故挚友 / 恋人 / 绑定对象**做的衣服：遗物心情（默认 +4，**只叠一层**）。
5. （可选）设置打开战斗加成：制作者存活且同房间时，主武器约 **+2%** 命中/伤害，封顶不叠。

**不记录**：食物、毒品等一次性消耗品。

**一期不做**：敌人因「恨屋及乌」仇视某匠人的装备。

## 设置

选项 → 模组设置 → 匠人署名：

| 项 | 默认 |
|----|------|
| 总开关 | 开 |
| 武器 / 服装 / 艺术品 / 假体署名 | 开 |
| 检视显示 | 开 |
| 心情 | 开；自造 +2；遗物 +4 |
| 战斗加成 | **关**；+2% |

## 性能

- 署名只在**制作完成**时写 ThingComp。
- 心情 ThoughtWorker 只读身上服装的 comp。
- 不做全图「最近的剑」扫描。

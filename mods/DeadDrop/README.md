# 黑市邮筒 Dead Drop

RimWorld 1.6。地图边缘的**灰色订单**玩法：高回报、有暴露风险，必须殖民者亲自跑边交接。

## 理念

> 不是第二贸易商，也不是挂机印钞。接单是决策，交货是行动，暴露是可读的失败。

## 启用

1. **Harmony**
2. 模组列表启用 **黑市邮筒 Dead Drop**
3. 可选：**特质提取 Trait Extractor**（软联动血清订单）

路径：`Mods/DeadDrop`

## 玩法循环（Phase 1）

1. 研究 **灰色渠道 / grey channels**
2. 在地图**边缘**建造 **黑市邮筒石堆**（Misc 分类）
3. 每 **3～7 天**最多 **1** 笔活跃订单（信件 + 石堆检视）
4. 石堆 Gizmo：**接单 / 拒单**
5. 接单后，**搬运**工种殖民者走到石堆 **交接**（也可右键强制）
6. 成功：货/银入账，**黑市声望**↑ → 更好/更热订单
7. 失败（交货时 roll）：声望↓、某派系关系 **−15～−30**、可能出现小型**搜查队**（非灭村）

### 订单类型

| 类型 | 玩家做 | 玩家得 |
|------|--------|--------|
| 卖出 Sell | 交付毒品/器官/零件等 | 银币（约 1.3～2.0× 市价） |
| 买入 Buy | 付银 | 残次/违禁货（枪、药、血清…） |
| 交换 Both | 交货 + 可能付银 | 货 + 可能净银 |

### 声望（0～100）

- 成功 +5～+10；暴露大扣；拒单/过期小扣
- 高声望：更贵订单、双向交换、TE 血清（若已装）

### 轻松模式

- 暴露率 ×0.5
- 无搜查队
- 仍需研究 + 石堆 + 跑边 Job

## 设置

选项 → 模组设置 → 黑市邮筒：

- 总开关
- 刷新间隔、利润倍率、暴露率、搜查队、关系打击
- 善良殖民者拒单、轻松模式
- TE 联动状态只读提示

## 性能

- **不**扫描 `map.AllCells`
- `MapComponent` 每小时稀有脉冲；无订单且无石堆时几乎休眠
- 物品计数走 `listerThings.ThingsOfDef`

## 编译

```bash
dotnet build Mods/DeadDrop/1.6/Source/DeadDrop/DeadDrop.csproj -c Release
```

`RimWorldDir` / `RIMWORLD_DIR` 可移植。输出：`1.6/Assemblies/DeadDrop.dll`

## 不做（有意）

- 全自动挂机收黑钱
- 无限堆叠订单
- 与原版走私无区分的纯加价商店

## 兼容

- Harmony 必需
- Soft-link Trait Extractor（`TE_TraitSerum`，`GetNamedSilentFail`）
- 中英 Keyed + DefInject

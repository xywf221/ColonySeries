# 粉丝转盘 FanWheel

为主播设计：把粉丝/观众的打赏昵称做成抽奖奖池，随机给殖民者命名。

## 功能

- **粉丝名称池管理**（Mod 设置里）：批量粘贴添加（一行一个，自动去重）、一键清空（带确认）、列表单个删除；
- **大转盘**：打开殖民者「重命名」对话框，奖池非空时「随机」按钮上方出现「转盘」按钮；
  点击弹出 GL 彩色轮盘，转动时带 tick 音、缓出动画，停下后中奖扇区金色闪烁；
- 中奖名称**写回昵称输入框**（不直接改名），点「确定」才生效，点「取消」不变；
- 中奖名称同时**移出奖池**，避免同一人被重复抽到。

## 兼容

- 只往 `Dialog_NamePawn` 加一个按钮、用其私有 `CurPawnNick` 写值，不改任何命名逻辑；
- 人类（`NameTriple`，改 Nick）与动物/机械（`NameSingle`）都支持。

依赖：Harmony。

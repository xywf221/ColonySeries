# 田作 Fieldcraft

RimWorld 1.6。**地力预算**与养地循环。与 [垦壤工程 Landworks](../Landworks) **软联动**（可选，不强制）。

## 理念

> 地力是预算；Landworks 改的是账户额度，田作花的是流水。

不是超级作物包，也不是免费肥土。收获扣地力，堆肥追肥回充；耗尽则生长变慢，人工沃土更快板结。

## 启用

1. **Harmony**
2. 模组列表启用 **田作 Fieldcraft**
3. 建议同时启用 **垦壤工程 Landworks**（可选，联动更深）

路径：`Mods/Fieldcraft`

## 玩法

### Phase 1 — 地力与堆肥

1. 研究 **地力预算**
2. 在可耕地上种植；检视显示 **地力预算**
3. 干草/木材做 **田作堆肥**（**堆肥工场** 后可建 **堆肥坑**）
4. **田作** 分类 → **追肥**
5. 收割有几率残茬还田

### Phase 2 — 休耕 / 水田 / 绿肥

6. 研究 **轮作休耕** → **标记休耕**（空田缓慢回充；连作同种作物额外耗地）
7. 研究 **水田工程** → **筑田/灌水** / **排水**  
   - 土壤 → 干水田 → 淹水田  
   - 水稻在淹水田生长加成；其他作物略减  
   - 地力极低时淹水田可能干涸
8. 研究 **绿肥** → 种植 **绿肥三叶草** 或对干草草等 **耕入还田**（无收获物，高回充）

### 有 Landworks 时

- 工程土自动纳入预算
- 零地力 **加速** 退化计时 → 可板结
- 追肥刷新改良/耕作层维持
- 双堆肥（田作 / 垦壤）都可用于追肥

### 无 Landworks 时

- 原生可耕土轻量预算（设置可关）
- 无板结地形 rewrite（无对应 def）

## 研究树

```
地力预算 ─┬─ 堆肥工场
         ├─ 轮作休耕 ── 绿肥
         └─ 水田工程
```

## 设置

选项 → 模组设置 → 田作：

- 收获耗地、漏失、追肥、残茬
- 休耕回充、绿肥倍率、连作惩罚
- 脉冲性能、跟踪原生土、轻松模式
- Landworks 联动状态

## 性能

- 不扫描 `map.AllCells`
- 预算 / 休耕字典 + 事件驱动
- 脉冲批次上限

## 编译

```bash
dotnet build Mods/Fieldcraft/1.6/Source/Fieldcraft/Fieldcraft.csproj -c Release
```

`RimWorldDir` / `RIMWORLD_DIR` 可移植。输出：`1.6/Assemblies/Fieldcraft.dll`

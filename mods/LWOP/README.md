# LWOP Package [ColonySeries]

LWOP Package is an overpowered convenience mod for RimWorld 1.6.

## Features

- Adds LWOP steel, LWOP wool, LWOP stone blocks, LWOP nutrient agents, and many crafting/refining recipes.
- Adds powerful melee and ranged weapons, LWOP power armor, and several equipment ability buttons.
- Adds LWOP bionics, chips, quick surgeries, and body-part removal recipes.
- Adds the universal LWOP worker mech, able to fight, haul, clean, build, grow, mine, craft, doctor, research, handle animals, and provide childcare.
- Adds LWOP storage racks, power buildings, security buildings, pollution pump, air conditioner, transport pods, and transport ship.
- Adds LWOP floors, meditation sculptures, food buffs, and extra resource conversion recipes.

## Compatibility

Requires Harmony (brrainz.harmony).

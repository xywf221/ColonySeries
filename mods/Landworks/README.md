# 垦壤工程 Landworks

面向 RimWorld 1.6 的**有代价地形改造**模组。

不是“免费铺肥土”。改地要挖土、花工时、造堆肥；人工沃土会退化，改造过多会触发地质反噬。

## 启用

1. 确保已启用 **Harmony**
2. 在模组列表启用 **垦壤工程 Landworks**
3. 新开或读档均可（读档立即生效）

路径：`Mods/Landworks`

## 玩法循环

1. 研究 **基础土方**
2. 打开 **垦壤** 建筑分类 → **挖掘取土**
3. 殖民者挖土获得 **填土**，原地留下 **取土创面**
4. 用填土铺 **垦复土壤**（砂石/贫瘠地 → 可耕）
5. 研究 **堆肥学**，用干草/木材做 **堆肥**，铺 **改良沃土**
6. 研究 **田间耕作** 可铺短期高肥 **耕作种床**（会沉降）
7. **排水工程 / 水力改地** 处理沼泽与浅水（深水/深海不行）
8. 中后期建 **土壤稳定器**（耗电）维持人工土壤、降低地质压力

## 难度设计

| 机制 | 作用 |
|------|------|
| 质量守恒 | 填土必须从别处挖来，挖处变差 |
| 工时成本 | 取土走采矿速度，铺地 WorkToBuild 偏高 |
| 材料成本 | 堆肥耗干草/木材；堤填耗大量填土+钢/木 |
| 退化 | 改良沃土/耕作层无稳定器会回落甚至板结 |
| 地质压力 | 铺人工地形累计压力，过高出信并提高反噬几率 |
| 反噬事件 | 土壤塌陷、泥沼回潮，把工程成果打回原形 |
| 情绪 | 挖土给短暂“浑身是泥”心情惩罚 |

## 设置

选项 → 模组设置 → Landworks（可滚动，可一键恢复默认）：

**平衡**
- 地质压力增速 / 自然衰减 / 每次挖掘压力
- 人工沃土、耕作层维持天数
- 填土产量倍率、挖掘工时倍率
- 反噬强度、反噬最低压力阈值

**土壤稳定器**
- 作用半径、每日减压量

**性能**（只影响后台脉冲，不改规则）
- 后台脉冲间隔（默认 2500 tick ≈ 1 游戏小时）
- 每脉冲最多处理的退化格数（默认 64，大农场轮询）

**开关**
- 是否启用反噬事件
- **轻松模式**（降压力与反噬，仍保留材料工时）

### 性能说明

稳态不再扫描整张地图：
- 只维护「工程地形 / 可退化」单元格集合
- Harmony 热路径先廉价过滤，字段访问已缓存
- 退化计时按批次上限轮询；稳定器用半径平方判断，不建全图 HashSet

## 编译

工程文件不写死盘符。默认假定布局为：

` <游戏根目录>/Mods/Landworks/1.6/Source/Landworks/Landworks.csproj `

在游戏根目录下：

```bash
dotnet build Mods/Landworks/1.6/Source/Landworks/Landworks.csproj -c Release
```

若工程不在默认相对位置，任选其一指定游戏根目录：

```bash
# MSBuild 属性
dotnet build -c Release -p:RimWorldDir="D:\Games\RimWorld"

# 或环境变量
export RIMWORLD_DIR="D:/Games/RimWorld"   # Windows Git Bash / Linux / macOS
set RIMWORLD_DIR=D:\Games\RimWorld        # cmd
```

Harmony 引用顺序：
1. `-p:HarmonyPath=...\0Harmony.dll`（若指定）
2. 游戏 `Mods` 下常见 Harmony 安装路径
3. 否则自动用 NuGet `Lib.Harmony`（仅编译，不拷进 Assemblies）

输出：`Mods/Landworks/1.6/Assemblies/Landworks.dll`

## 兼容

- 需要 Harmony
- 与 Tilled Soil 等“免费肥土”模组理念冲突，可同开但建议二选一
- 未改原版地形数值，仅新增内容
- 可选联动：**田作 Fieldcraft**（`Mods/Fieldcraft`）——地力预算、追肥、残茬还田；软链接本模组，不强制同开

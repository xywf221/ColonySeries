# 聚落账房 Ledger v2

RimWorld 1.6。**信用杠杆**：主动预支银币 → 到期还 / 展期 / 违约。  
**不是**每周报表税，**不是**电费/储备心情农场。

权威设计：`mod-design-review.md` §2.5。

## 理念

> 赊账是按钮，不是天气。玩家点「预支」才有债；还清涨信用，违约砸关系。

## 启用

1. **Harmony**
2. 模组列表启用 **聚落账房 Ledger**

路径：`Mods/Ledger`

## 玩法循环

1. 选中任意可控殖民者 → 看到账房 Gizmo
2. **预支信用**：浮选金额（50 / 100 / 250… 与额度上限）  
   - 在殖民者旁**掉落银币**  
   - 向可见**非敌对**派系记一笔债（默认约 7 日到期）  
   - 额度 = `信用 × 倍率 − 已欠`（默认倍率 15；信用须 ≥ 门槛，默认 25）  
   - 预支冷却约 1 小时，防连点刷
3. **偿还**：最旧一笔快捷还，或菜单选债；扣地图银，信用↑、关系微涨
4. **展期**：每笔一次，新到期日，信用小损
5. **到期**：先催收信 → 再拖一天 → **违约**（信用大损、关系打击；敌对派系可能小讨债队；轻松模式多半只有信）
6. **查账**：状态信列出信用 / 未偿 / 可赊
7. 大额诚实成交：信用微涨（TradeDeal 成功后的小 bump）

### 默认不做

| 项 | 状态 |
|----|------|
| 抽象电费扣银 | **删除** |
| 永久全局贸易加价 | **删除** |
| 低储备心情 | **默认关**（设置可开） |
| 原版交易「银不够仍成交」 | **不做**（原版不允许；杠杆走预支） |

### 轻松模式

- 信用负面变化 ×0.5
- 违约讨债偏信件

## 设置

选项 → 模组设置 → 聚落账房：

- 总开关、轻松模式、预支开关
- 额度倍率、期限天数、最低信用
- 强制周报、储备心情、讨债事件

## 性能

- `GameComponent` 每小时稀有脉冲；无债时几乎只做周报判断
- **不**扫 `map.AllCells`；银币用 `listerThings` / `resourceCounter`

## 编译

```bash
dotnet build "Mods/Ledger/1.6/Source/Ledger/Ledger.csproj" -c Release
```

可移植 `RimWorldDir` / `RIMWORLD_DIR`。输出：`1.6/Assemblies/Ledger.dll`

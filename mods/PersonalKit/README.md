# 个人小工具 PersonalKit

个人向小功能集合（RimWorld 1.6）。后续功能会往这里加。

## 当前功能

### 交易谈判加成上限

原版 1.6 在 `TradePriceImprovement` 上写了 `<maxValue>0.395</maxValue>`，约等于 +40% 硬顶。

**选项 → 模组设置 → 个人小工具 → 交易：**

| 选项 | 说明 |
|------|------|
| 不设上限（默认） | 接近旧版，社交带来的交易加成完整生效 |
| 自定义上限 | 关闭「不设上限」后，滑条 40%–300% |
| 买入价地板 | -50% ~ +50%，默认 0%（无地板），可让对面倒贴钱 |

### 技能衰减倍率

原版高等级技能（18-20）衰减很快。滑条 0x–3x，设为 0 = 禁止衰减。

### 激情 / 学习速率倍率

原版硬编码激情倍率（无=0.35x、兴趣=1x、燃烧=1.5x）。滑条 0.5x–5x，整体缩放学习速率。

### 社交冲突频率

滑条 0x–2x，设为 0 = 禁止社交打架。

### 囚犯招募难度

每次谈话削减的抗性倍率。滑条 0.5x–5x，设为 5x = 每次谈话削减 5 倍抗性。

### 手术成功率保底

滑条 0%–100%。设为 80% = 每次手术有 80% 概率强制成功，剩余 20% 走原版判定。

### 倒地保留武器

勾选后，己方殖民者倒地时主武器自动收入背包而非掉落在地。

### 制作品质下限

滑条关闭 / Awful–Legendary。设为 Good = 工匠制作的物品最低 Good 品质。

### 灵感触发频率

原版灵感 MTB 约 10–210 天（取决于心情）。滑条 0.25x–3x，设为 0.25x = 触发频率 ×4。

### 穿梭机攻击目标

勾选后，客用穿梭机（Odyssey DLC）成为合法攻击目标，优先级与普通建筑相同（TargetPriorityFactor=0.4f）。需重启/重载生效。

### 心灵同调装置（Royalty）

| 选项 | 说明 |
|------|------|
| 范围 | 原版 30 格；滑条 5–500 格，改 hediff comp 的 `range`（施加与丢弃判定共用） |
| 心情加成比例 | 原版 100%；滑条 0%–1000%，乘以 `Thought_PsychicHarmonizer.MoodOffset` 最终值（好心情与坏心情都乘） |
| 互相叠加 | 原版：已有同调植入者互不接收；开启后附近每个携带者各施加一条可叠加心情 |
| 拆除启灵等级 | 手术「extract psylink level」：降 1 级并生成启灵装置；关 = 手术不可用 |

### 心灵抚慰脉冲发生器（神器）

一次性神器「心灵抚慰脉冲发生器」原版给全图每人一条 +15 心情记忆，持续 1 天，最多叠 3 层。

| 选项 | 说明 |
|------|------|
| 心情值 | 原版 +15；滑条 -100 ~ +100，**直接设定具体数值** |
| 持续时间 | 原版 1 天；滑条 0.1–30 天。**已获得的记忆沿用创建时的时长**，改动在下一次脉冲生效 |
| 叠加上限 | 原版 3 层；滑条 1–20。调高后连续使用可持续叠加 |

调成负数（例如 -30）后，脉冲就从「抚慰」变成了一场全图范围的心灵折磨。

### 心灵放射器（建筑）

通电的建筑「心灵放射器」原版给 15 格内每人 +5 心情（可穿墙）。

| 选项 | 说明 |
|------|------|
| 心情值 | 原版 +5；滑条 -100 ~ +100，直接设定具体数值。负数 = 吸心情的装置 |
| 作用半径 | 原版 15 格（原版硬编码常量）；滑条 1–200 格 |

### 心灵抚慰 / 灵能低语（事件）

原版随机事件 `PsychicDrone` 共 5 档：第 0 档是正面的「心灵抚慰」+16，第 1–4 档是负面的「灵能低语」-12 / -22 / -30 / -40。

| 选项 | 说明 |
|------|------|
| 心灵抚慰（正面事件） | 原版 +16；滑条 -100 ~ +100 |
| 灵能低语（最高档） | 原版 -40；滑条 -100 ~ +100。低/中/高三档按原版比例自动得出（默认 -12 / -22 / -30 / -40），面板会实时显示四档数值 |

两者独立，且都可正可负：

- 把**灵能低语**调成正数 → 袭击期反而全员心情高涨（原版最难受的事件变成 buff）
- 把**心灵抚慰**调成负数 → 所谓的好事也变成坏事
- 设 0 = 对该事件完全免疫

> 所有心情值都受原版心灵敏感度（`PsychicSensitivity`）缩放，所以心灵敏感度 0 的小人依然完全免疫，负数也不会强加给他们。

### 战利品表编辑器

原版的战利品池（`ThingSetMakerDef`）是 XML 里写死的：Ideology 远古建筑的每个房间角落、奖励箱、任务掉落都在 `<thingDefs>` 里逐个列举，游戏内无法改动。

本模组让它**运行时可编辑**：加物品、删物品、分层调概率。

| 选项 | 说明 |
|------|------|
| 启用战利品表编辑 | 总开关。关闭 = 所有池完全按原版走，不留任何残留 |
| 池 | 下拉选择要编辑的池，自动扫描已加载的全部 def |
| 分组权重 | 该分组被抽中的相对权重（灰色 = 原版值） |
| 组内权重 | 物品在组内的相对概率，**填 0 = 永不出现** |

点分组左边的 `+` 展开物品列表，`+ 添加物品` 打开可搜索选择器（含其它模组的物品）。

**分组名称**：原版的 `ThingSetMakerDef` 没有给分组起过名字 —— 189 个分组没有一个 `<label>`，官方 `ThingFilter.Summary` 的兜底也只是通用文案。所以这里用**组内第一件物品**来命名列表中的每行。这符合原版数据结构：**63% 的分组（119 / 189）本来只装 1 件物品**，13 个池更是每组都只有 1 件 —— 对这些分组来说物品名就是组名，不会额外加「共 1 项」这种没意义的后缀。多物品的分组（如远古建筑高级房里 23 件的那一组）才会标注数量，鼠标悬停可看完整清单。

**动态分组只能调权重**：少数分组没有固定物品名单，由生成器在抽取时按研究进度等状态决定内容 —— 远古建筑里的**设计图**分组就是 `ThingSetMaker_Techprints`（`MapGen_AncientComplexRoomLoot_Better` 的第 11 组，原版权重 0.05）。这类分组显示为「动态生成」，**只能改它的分组权重**，不能增删物品或调组内概率（它没有 `ThingFilter` 可供修改）。想让设计图更容易出，把它的权重从 0.05 调高即可。

**池是自动发现的**，不写死名单：装新 DLC 或其它模组后它们的池会自动出现在下拉里。只收录 `RandomOption` 根的池 —— `ThingSetMaker_Sum` 用的是 `chance`（每项独立掷骰，不是相对权重），语义不同，故不支持。

**为什么组内权重也要单独做**：原版组内是**等概率**抽取（`StackCount` 走 `TryRandomElement`），根本没有权重概念。所以组内权重只对**你编辑过的分组**生效，未编辑的分组完全保持原版行为。

**还原是精确的**：删掉某分组的覆盖、或关掉总开关，该分组的权重、物品名单、生成器实例全部回退到原版状态，不会复合叠加。

### 意识形态风格（Ideology）

**原版怎么改：** 意识形态面板 → 编辑教义 → **风格分类**（Style categories）。多分类时**最左边**优先。部分模因（如「以痛为德 / 食人」）会强制挂上 **Morbid（病态）**，所以桌椅变成骷髅风。

**本模组：** 设置 → 意识形态 → **关闭病态桌椅风格**。开启后解析风格时跳过 Morbid，并清理已有病态外观；新建造也不再套病态。

未装对应 DLC / 无该 def 时静默跳过。

### 亡者衣物（Combat / 洗衣）

原版中，被尸体穿过的衣物（tainted）会：标签前缀加「亡」（部分中文包），穿上掉心情，商人大幅折价收购。

**两种方式处理：**

| 方式 | 设置项 | 说明 |
|------|--------|------|
| 直接洗 | **战斗 → 把被尸体穿过的衣物视为干净** | 一拍手，全图「亡」衣物当即变干净（无亡字、可穿、可原价卖） |
| 洗衣机 | **洗衣 → 洗衣机**（研究「洗衣基础」） | 建造电动洗衣机，用「指定洗衣」设计器标记**任意衣物**，crafting 系小人搬进机器洗：亡者污损被洗掉，同时扣一点耐久。有真实代价：耗电、耗时、占地、耐久损耗；比「一键洗」更有 RimWorld 味 |

洗衣机细节：
- 建筑：`PK_Washer`，2×1，需电力（240W，可拉闸），造价钢150+零件6。
- 指定：建筑师菜单「洗衣」分类 → **指定洗衣**工具，可框选任意未被穿戴/未禁止的衣物（有无污损都行）。
- 工作：Crafting 优先级内 10，需 Manipulation。
- 洗一件：按通用劳动速度耗工时（设置里单次耗时 50%–300%）。
- 耐久：每次洗涤扣最大耐久 0%–50%（滑条，默认 10%），0 = 不磨损。
- 污损：洗到带「亡」的衣物会移除污损；洗完后清除该衣物的洗衣指定，不会反复洗。
- 与「视为干净」互斥：开了后者则全图衣物都不带污损——洗衣机浪费耐久，建议只开其一。

### 心灵冲击脉冲发生器（新增神器）

一次性神器 **`PK_PsychicShockPulser`**，激活后让**地图上所有敌对与无阵营单位**陷入心灵冲击（意识上限压到 10%）而倒地。

| 选项 | 说明 |
|------|------|
| 总开关 | 关闭后神器仍会掉落，但激活时不产生任何效果 |
| 倒地时长 | 滑条 0.5–24 小时，默认 3 小时（与原版 `PsychicShock` 一致） |

**目标筛选**（不会误伤自己人）：

| 对象 | 是否倒地 |
|------|---------|
| 敌对派系（袭击者、海盗…） | ✓ 倒地 |
| 无阵营野怪（狂暴动物等） | ✓ 倒地 |
| 己方殖民者 / 驯服动物 / 囚犯 / 奴隶 | ✗ 免疫 |
| 中立商队、访客 | ✗ 免疫 |
| 心灵敏感度为 0 的单位（机械族等） | ✗ 免疫 |

**代价**：一次性消耗品（使用后销毁）+ 对每个受影响派系 -200 好感 + 激活时 132 tick 前摇（期间会被打断）。

**获取途径**（与原版神器一致）：

| 来源 | 说明 |
|------|------|
| 商队 / 轨道商人 / 定居点商店 | 自动上架：按 `tradeTag = Artifact` 随机取货 |
| 远古危险（神殿）| 自动出现：按 `thingCategories = Artifacts` 筛选 |
| 通用任务奖励池 | 自动出现：走 `RewardStandardHighFreq` 标签 |
| 远古建筑高级房 / 安保箱（Ideology）| 已注入 defName 列表 |
| 血肉袋掉落 / 灰盒奖励（Anomaly）| 已注入 defName 列表 |
| 远古保险箱 / 高价值箱（Odyssey）| 已注入 defName 列表 |

即：前三类靠原版标签机制自动生效，后面这几个是显式 defName 白名单，需要 `Patches/PK_ThingSetMakers.xml` 里的 PatchOperation 注入，否则刷不出来。未装对应 DLC 时自动跳过。

与原版`心灵冲击枪`的区别：冲击枪是单体、需要视线、有 30% 脑损伤风险；本神器是全图、无需视线、无脑损伤，但只能对敌对/无阵营生效，且是一次性的。

### 双人床：强制滚床单

勾选后，分配给殖民者的**双人床**（非医疗 / 非囚犯 / 非奴隶床）多出一个命令 **强制滚床单**。点击后，分配到该床的爱侣立刻开始滚床单——即使正在忙别的也会赶来。

- 需要至少一名清醒、有在世恋人（配偶/恋人/未婚妻）的床位主人。
- 只是**下发原版滚床单工作**：两人自行走到床边躺下、按原版流程进行，不绕过同意/情境判定，也不会凭空制造恋爱关系。
- 会清空双方的滚床单冷却（`canLovinTick`）。

## 设置约定

每个功能都有**独立开关**；关闭后该功能完全走原版逻辑。  
底部还有 **全部关闭（纯原版）** 一键关掉所有覆盖。

默认仅开启交易相关两项（谈判上限 + 买入价地板）；其余默认关闭，需手动勾选启用。

## 启用

模组列表启用 **个人小工具 PersonalKit**。需要 Harmony。

## 编译

```bash
dotnet build Mods/PersonalKit/1.6/Source/PersonalKit/PersonalKit.csproj -c Release
```

路径可移植：默认从 csproj 推断游戏根目录；也可用 `-p:RimWorldDir=...` 或环境变量 `RIMWORLD_DIR`。

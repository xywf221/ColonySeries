# Salvage Atlas — Phase 1 deviations

Core from `mod-design-review.md` section 2.8 preserved:

- Fragments != research points
- Bounded branches (3-4 ranks) -> one-shot blueprint / local buff / teardown recipe
- Failed teardown: waste fragments + small fire/explosion + letter
- Parallel to vanilla research
- No mechs -> mostly idle
- Settings + easy mode
- Player verbs: designate salvage, analyze at bench, choose unlocks

## Intentional Phase 1 choices

| Choice | Why |
|--------|-----|
| **Five branches** (Blueprints / Field kit / Teardown / Optics / Coolant) | Design asked 3-5 ranks per branch; five thin branches keep unlock choices interesting without a damage meta-tree. |
| **Physical fragment item + analyzed bank** | Makes haul/analyze a real verb; bank spends at bench gizmos. |
| **Kill drip 0-1 fragment** | Flavor only; designate salvage remains the main yield path so AFK kill-farming is weak. |
| **Field patches as disappearing hediffs** | Local, temporary, personal - explicitly not permanent global damage. |
| **Teardown designation separate from salvage** | Gated behind Teardown rank 1; failure letter is mandatory feedback. |
| **Blueprint credits -> schematic item** | One-shot loot package; decode float menu. |
| **Name-heuristic wreck targets** | Works on Core ship chunks without hard DLC deps; Odyssey ShipChunk_Mech included by name. |
| **DEV gizmos on bench** | +analyzed / +fragment items for playtest. |

## Not done (later)

- Dedicated analyze-spot building (bench only in Phase 1; float menu + WorkGiver).
- Biotech mechanitor soft-link recipes.
- UI tab listing full atlas tree (gizmos + inspect string suffice for Phase 1).

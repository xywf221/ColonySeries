# 特性提取器 Trait Extractor

RimWorld 1.6。用高风险手术提取特性 → 血清 → 注射给他人。

## 流程

1. 研究 **神经特性提取**（前置：医院床、医药生产；高科技研究台 + 多重分析仪）
2. 在机械加工台制作 **神经提取套件**
3. 对成人类人生物开医疗账单 **提取人格特性**  
   消耗：闪耀世界医药 ×1 + 提取套件 ×1 + 中性胺 ×20
4. 成功：失去该特性，地上掉落 **特性血清（具体特性名）**  
   必得神经创伤；可能永久疤痕；进入冷却
5. 注射方式：
   - 殖民者右键使用血清（自用）
   - 或医疗账单 **施用特性血清**（给囚犯/卧床患者）

## 平衡

| 限制 | 说明 |
|------|------|
| 研究门槛 | 中后期，需多重分析仪 |
| 材料 | 闪耀医药 + 套件（钢/元件/中性胺/工业医药） |
| 手术风险 | 成功率系数 0.65，失败可致死 |
| 必然后果 | 神经创伤、心情、旁观负面、冷却 |
| 永久代价 | 疤痕（意识 -5%） |
| 不可提取 | 场景强制、基因绑定、被抑制特性 |
| 侵犯 | `isViolation` + 有害手术历史事件 |
| 注射 | 默认 85% 成功；失败排异并毁血清 |
| 数量上限 | 默认每人最多 4 个非抑制特性 |
| 冲突 | 默认可替换冲突特性（可关） |

## 商人 / 据点进货

| 货源 | 提取套件（未提取工具） | 特性血清（已封装特性） |
|------|------------------------|------------------------|
| 外民据点 `Base_Outlander_Standard` | 约 50% 出 1–2 | 约 40% 出 1–2（随机特性） |
| 外民异域商队 | 0–2 | 1–3 |
| 外民批发商队 | 低概率 1 | — |
| 轨道异域商人 | 0–3 | 1–4 |
| 海盗商船/商队 | 低概率 | 低概率 1–2 |

商人血清按特性稀有度加权随机填充，常见特性更常见。套件可买卖；血清也可卖回。

## 设置

选项 → 模组设置 → 特性提取器：特性上限、注射成功率、疤痕率、冷却、是否允许殖民者提取、冲突替换、轻松模式等。

## 编译

```bash
dotnet build Mods/TraitExtractor/1.6/Source/TraitExtractor/TraitExtractor.csproj -c Release
```

路径可移植（`RimWorldDir` / `RIMWORLD_DIR`）。不依赖 Harmony。
